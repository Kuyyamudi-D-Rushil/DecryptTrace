# Evidence Model

## Evidence Semantics
Evidence generated by DecryptTrace establishes cryptographic and forensic relationships between a release event and an observed artifact.

- **Signed Release Evidence:** Establishes that a Sender's key authorized a release policy.
- **Signed Receipt Evidence:** Establishes that a Receiver's key acknowledged receipt of a watermarked payload.
- **Watermarked-Copy Provenance:** If a watermark is extracted from a leaked file, it demonstrates consistency with a recorded release. 

## Limitations of Evidence
- **Biological Identity:** Cryptographic evidence does not establish the biological identity of the human operating the machine.
- **Intentional Leakage:** A watermark match does not prove the authorized recipient intentionally leaked the material. Their system could have been compromised, or their keys stolen.
- **Framing Risk:** If the watermark secret (`K_wm`) is compromised, an attacker could forge watermarks to frame a legitimate recipient.
